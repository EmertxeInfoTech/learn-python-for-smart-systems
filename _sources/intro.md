# Learn Python for Smart Systems

**A beginner's tutorial by Emertxe Information Technologies**

This tutorial teaches Python from zero by building up to a real IoT project — a Smart Energy Optimization System that simulates environmental sensors and controls virtual HVAC devices.

---

## What You Will Learn

By the end of this tutorial you will be able to:

- Write Python programs using variables, conditions, loops, functions, and classes
- Read and understand a real multi-file Python project
- Modify an existing codebase with confidence
- Run a live Streamlit web dashboard

## No Prior Knowledge Required

This tutorial assumes you have never written a single line of code.

---

## How to Use This Tutorial

Work through the chapters **in order**. Each chapter builds on the previous one. Do not skip chapters. Do not skip exercises.

Use the **rocket icon** (🚀) at the top of any chapter to open it as a live interactive notebook — no installation needed.

```{admonition} Two Ways to Run
:class: tip

**Binder** — Click the Binder button. A live Python environment opens in your browser in about 2 minutes. No account needed.

**Google Colab** — Click the Colab button. Opens instantly. Requires a Google account.
```
