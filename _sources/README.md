# Learn Python for Smart Systems

A self-learning tutorial that teaches Python by building understanding of a real IoT project — a Smart Energy Optimization System that simulates environmental sensors and controls virtual HVAC devices.

## Who This Is For

Complete beginners. No prior programming experience required.

## What You Will Learn

- Python fundamentals: variables, conditions, loops, functions, classes
- How a real multi-file Python project is structured
- How to read and modify an existing codebase
- How to run a Streamlit web dashboard

## How to Use This Tutorial

Work through the notebooks in order. Each chapter builds on the previous one.

```
Part 1 — Python Fundamentals (Chapters 1–5)
Part 2 — The Project       (Chapters 6–8)
```

Do not skip chapters. Do not skip exercises.

## Setup

### Step 1 — Install Python
Download from https://python.org → choose version 3.10 or higher → install with default settings.

Verify:
```bash
python --version
```

### Step 2 — Install Jupyter
```bash
pip install notebook
```

### Step 3 — Open the tutorial
```bash
cd learn-python-for-smart-systems
jupyter notebook
```
Your browser will open. Click on the `notebooks/` folder and start with `Chapter_01`.

### Step 4 — Get the project files
Download or clone the Smart Energy Optimization System project. You will need it from Chapter 6 onward.
