# Learn Python for Smart Systems

A self-learning tutorial that teaches Python from zero by building understanding of a real IoT project — a Smart Energy Optimization System that simulates environmental sensors and controls virtual HVAC devices.

**Developed by:** Emertxe Information Technologies

---

## Read Online

**[emertxeinfotech.github.io/learn-python-for-smart-systems](https://emertxeinfotech.github.io/learn-python-for-smart-systems/)**

No installation required. Open any chapter and click the 🚀 launch button to run it live in Binder or Google Colab.

---

## Who This Is For

Complete beginners. No prior programming experience required.

## What You Will Learn

- Python fundamentals: variables, conditions, loops, functions, classes
- How a real multi-file Python project is structured
- How to read and modify an existing codebase
- How to run a Streamlit web dashboard

## The Project

From Chapter 6 onward, the tutorial uses the [Smart Energy Optimization System](https://github.com/EmertxeInfoTech/smart-energy-optimization-system) as the hands-on codebase.

## How to Use This Tutorial

Work through the chapters in order. Each chapter builds on the previous one. Do not skip chapters. Do not skip exercises.

```
Part 1 — Python Fundamentals (Chapters 0–5)
Part 2 — The Project         (Chapters 6–8)
```

### Option 1 — Read Online (recommended)

Visit **[emertxeinfotech.github.io/learn-python-for-smart-systems](https://emertxeinfotech.github.io/learn-python-for-smart-systems/)** and click the 🚀 button on any chapter page.

- **Binder** — full Jupyter interface, no account needed, 2–3 min first load
- **Google Colab** — instant start, requires a Google account

### Option 2 — Run Locally

```bash
# Install Jupyter
pip install notebook

# Clone this repo
git clone https://github.com/EmertxeInfoTech/learn-python-for-smart-systems.git
cd learn-python-for-smart-systems

# Open the tutorial
jupyter notebook
```

Your browser will open. Navigate to the `notebooks/` folder and start with `Chapter_00`.
