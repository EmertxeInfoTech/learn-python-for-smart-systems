Chapter 8 — Experiments#

Time: ~1 hour
Goal: Modify the project yourself. Each experiment touches a different layer of the system.

This chapter has no new concepts. It is entirely hands-on. Each experiment tells you exactly what to change and asks you to observe and explain the result.

Work on the actual project files — not this notebook.

Experiment 1 — Change the Temperature Threshold#

File to edit: src/config.py
Change: Set DEFAULT_THRESHOLD = 22.0

Steps:

  1. Open src/config.py and change the value

  2. Run python3 src/main.py

  3. Watch the output for 10–15 cycles

Answer these questions:

  1. Is the AC ON more often or less often compared to the default threshold of 26°C? Why?

Your answer:

  1. What are the exact upper and lower hysteresis bounds with the new threshold and the default buffer of 1.5°C?

Your answer:

  1. How does the total energy at the end of 20 cycles compare to the default? More or less? Why?

Your answer:

Reset: Change DEFAULT_THRESHOLD back to 26.0 before the next experiment.

Experiment 2 — Make the Room Always Occupied#

File to edit: src/sensor.py
Change: In get_data(), replace the occupancy line:

# Original:
"occupancy": random.choices([1, 0], weights=[70, 30])[0],

# Change to:
"occupancy": 1,

Steps:

  1. Make the change

  2. Run python3 src/main.py for 20 cycles

  3. Observe the AC column

Answer these questions:

  1. Does Rule 1 (“Room is unoccupied → AC OFF”) ever trigger now? Why or why not?

Your answer:

  1. Is total energy consumption higher than before? Explain the reason.

Your answer:

Reset: Revert sensor.py to random.choices([1, 0], weights=[70, 30])[0].

Experiment 3 — Add a New Field to the Record#

This experiment adds a "reason" field to the terminal output. Currently main.py does not print the reason why the AC turned on or off — only the dashboard does. Let’s fix that.

File to edit: src/main.py

Step 1: In the record dictionary inside main(), add a new key:

record = {
    "timestamp":         datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
    "temperature":       data["temperature"],
    "humidity":          data["humidity"],
    "occupancy":         data["occupancy"],
    "hour":              data["hour"],
    "ac_state":          ac_state,
    "cycle_energy":      cycle_energy,
    "cumulative_energy": calculator.get_cumulative(),
    "reason":            engine.last_reason,    # ← add this line
}

Step 2: Below the existing print(...) statement, add:

print(f"  → {record['reason']}")

Step 3: Run python3 src/main.py and verify the reason prints under each cycle.

Experiment 4 — Add a New Metric to the Dashboard#

Add a metric that shows the current hour of day on the dashboard.

File to edit: src/dashboard.py
Function to edit: render_dashboard()

Find the line with four columns:

col1, col2, col3, col4 = st.columns(4)

Change it to five columns and add a fifth metric:

col1, col2, col3, col4, col5 = st.columns(5)
col1.metric("Temperature (°C)", f"{latest['temperature']:.1f}")
col2.metric("Humidity (%)",     f"{latest['humidity']:.1f}")
col3.metric("Occupancy",        "Occupied" if latest["occupancy"] else "Empty")
col5.metric("Hour",             f"{latest['hour']:02d}:00")   # ← new

Run the dashboard and verify the new metric appears.

Experiment 5 — Open-Ended: Your Own Change#

Design and implement one change of your own. It must:

  • Touch at least one .py file in src/
